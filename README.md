# Portfolio - React & Tailwind CSS

Đây là mã nguồn cho trang Web Portfolio cá nhân dạng Single-page, được xây dựng bằng React (Vite) và Tailwind CSS.

## Cấu trúc thư mục

- `public/avatar.jpg`: Ảnh đại diện của bạn.
- `src/App.tsx`: Chứa toàn bộ giao diện 4 phần (Header/Hero/Academics/Experience/Contact).
- `src/index.css`: Cấu hình CSS toàn cục & Tailwind.
- `tailwind.config.js`: Cấu hình màu sắc, font chữ theo chuẩn.

## Hướng dẫn chạy thử (Local Development)

Nếu bạn đã cài đặt **Node.js** trên máy tính:

1. Mở Terminal (Command Prompt / PowerShell).
2. Di chuyển vào thư mục dự án này:
   ```bash
   cd portfolio
   ```
3. Cài đặt thư viện:
   ```bash
   npm install
   ```
4. Chạy server phát triển (Dev Server):
   ```bash
   npm run dev
   ```
5. Mở trình duyệt và truy cập vào đường dẫn `http://localhost:5173`.

## Các công nghệ sử dụng
- **React (Vite):** Framework hiện đại, khởi động nhanh.
- **Tailwind CSS:** Hỗ trợ tạo giao diện Responsive nhanh chóng.
- **Lucide React:** Bộ icon đẹp mắt chuẩn hiện đại.
- **Google Fonts (Inter):** Font chữ chuẩn cho UI/UX chuyên nghiệp.
